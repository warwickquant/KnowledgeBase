Have an idea for a new quantitative finance project? Consider:
1. Defining clear research questions
2. Identifying required data sources
3. Reviewing relevant literature
4. Proposing methodology
5. Forming a team

Submit your proposal by creating a new markdown file in this directory following the existing project templates.
