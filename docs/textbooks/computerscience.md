# Computer Science Textbooks

Essential computer science foundations for quantitative finance, including deep learning and reinforcement learning.

---

## Deep Learning

### Deep Learning
**Authors**: Ian Goodfellow, Yoshua Bengio, and Aaron Courville  
**Publisher**: MIT Press, 2016  
**Link**: [MIT Press](https://www.deeplearningbook.org/)

**Description**: Comprehensive introduction to deep learning covering neural networks, optimization, convolutional networks, sequence modeling, and generative models. Essential for applying deep learning to financial prediction, feature extraction from alternative data, and reinforcement learning for trading. Accessible to readers with linear algebra and probability background. Free online version available.

**Key Topics**: Backpropagation, CNNs, RNNs, regularization, optimization algorithms

---

## Probabilistic Machine Learning

### Probabilistic Machine Learning: An Introduction
**Author**: Kevin Murphy  
**Publisher**: MIT Press, 2022  
**Link**: [PML Book](https://probml.github.io/pml-book/book1.html)

**Description**: Modern treatment of machine learning from a probabilistic perspective. Covers supervised learning, Bayesian methods, graphical models, and deep learning with emphasis on uncertainty quantification. Valuable for building robust trading models that account for prediction uncertainty. Includes Python code examples using JAX.

**Key Topics**: Bayesian inference, probabilistic graphical models, Gaussian processes, variational inference

## Reinforcement Learning

### Reinforcement Learning: An Introduction
**Authors**: Richard S. Sutton and Andrew G. Barto  
**Publisher**: MIT Press, 2018 (2nd Edition)  
**Link**: [MIT Press](http://incompleteideas.net/book/the-book.html)

**Description**: Definitive introduction to reinforcement learning covering dynamic programming, Monte Carlo methods, temporal-difference learning, and function approximation. Critical for developing adaptive trading strategies, optimal execution algorithms, and portfolio management systems. Clear explanations with focus on fundamental concepts. Free PDF available from authors.

**Key Topics**: Markov decision processes, Q-learning, policy gradients, actor-critic methods

### Algorithms for Reinforcement Learning
**Author**: Csaba Szepesvári  
**Publisher**: Morgan & Claypool, 2010  
**Link**: [Morgan & Claypool](https://sites.ualberta.ca/~szepesva/papers/RLAlgsInMDPs.pdf)

**Description**: Concise overview of core RL algorithms with mathematical rigor. Covers value iteration, policy iteration, and approximate methods. Excellent companion to Sutton & Barto for readers seeking algorithmic details and convergence proofs. Free PDF available from author's website.

**Key Topics**: Dynamic programming, function approximation, convergence analysis
