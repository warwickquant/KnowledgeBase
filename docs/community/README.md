# Community Contributions

Contribute to the Warwick Quant knowledge base and share your research.

## How to Contribute

### Suggesting Resources
Recommend a textbook, website, podcast, or social media account:
1. Check it's not already listed
2. Verify it's high-quality and relevant to quantitative finance
3. Submit via GitHub issue or pull request

### Contributing Code
Add well-documented code to `tutorials/` directory:
- Clear comments and example usage
- List dependencies
- Include test cases or expected output

### Sharing Research Papers
Submit a 1-2 paragraph summary to [Papers](./papers.md):
- Full citation with link
- Key findings and methodology
- Relevance to society projects

### Improving Documentation
Submit pull requests for fixes or improvements.

## Quality Standards
- **Accuracy**: Verify information before contributing
- **Clarity**: Write concise, clear explanations
- **Attribution**: Cite sources properly
- **Relevance**: Keep on-topic (quantitative finance)

## Code of Conduct
- **Respectful**: Treat all members with respect
- **Collaborative**: Help others learn and grow
- **Honest**: Give credit where due, cite sources
- **Professional**: Maintain academic standards

**Unacceptable**: Plagiarism, sharing confidential information, harassment, spam

## Contact
- **GitHub**: [warwickquant/KnowledgeBase](https://github.com/warwickquant/KnowledgeBase)
- Open a GitHub issue with questions

Your contributions make this knowledge base valuable for current and future members. 📈
